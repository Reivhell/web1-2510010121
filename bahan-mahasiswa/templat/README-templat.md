## Fitur

- (contoh) Halaman beranda dan formulir yang responsif (ponsel, tablet, desktop)
- (contoh) Katalog dimuat dari `data/katalog.json` menggunakan Fetch API
- (contoh) Pencarian dan filter kategori
- (contoh) Validasi formulir dengan JavaScript
- (contoh) Widget jadwal salat dari API publik

## Teknologi

HTML5, CSS3 (Flexbox, Grid, media query), JavaScript (DOM, Fetch API), Git, dan GitHub Pages.

## Cara Menjalankan di Komputer

1. Salin (*clone*) repositori ini.
2. Buka foldernya di Visual Studio Code.
3. Klik kanan `index.html`, lalu pilih **Open with Live Server**.

> Halaman harus dibuka melalui server (Live Server atau GitHub Pages), bukan dengan klik ganda berkas,
> karena `fetch()` tidak dapat membaca berkas JSON dari alamat `file://`.
